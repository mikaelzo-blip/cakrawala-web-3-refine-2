# CBL Website — Human-Led Art Direction

## Objective
Create a premium corporate portfolio for CV Cakrawala Buana Lestari that feels authored by an experienced design studio, not generated from a generic AI website prompt.

## Creative Direction
**Editorial + Industrial + Architectural + Premium Corporate**

The website should communicate engineering credibility through composition, typography, authentic project documentation, measured motion, and disciplined spacing. The visual system must feel specific to CBL and its real project work.

## Core Principles
1. Photography is evidence, not decoration. Prefer authentic CBL project documentation over generic stock imagery.
2. Typography carries hierarchy. Use type scale, spacing, alignment, whitespace, and contrast instead of decorative UI containers.
3. Sections should have distinct compositions. Avoid repeating centered heading + card grid patterns.
4. Motion must explain hierarchy or spatial continuity. Do not animate elements merely because animation is available.
5. Corporate credibility beats visual gimmicks. No fabricated metrics, testimonials, awards, clients, or project claims.
6. Use brand orange sparingly as an accent/action color.
7. Mobile must be intentionally composed, not simply desktop stacked vertically.

## Anti-AI-Slop Rules
Do not introduce these patterns unless there is a documented design reason:
- generic purple/blue gradients
- decorative blur blobs
- glassmorphism panels
- oversized rounded cards everywhere
- pill badges used as default section labels
- chip clouds for ordinary service lists
- floating stat/info cards over hero imagery
- icon in every heading/card
- three-column feature-card grids as the default layout
- identical card treatment across unrelated sections
- glowing buttons
- excessive shadows
- generic SaaS hero composition
- fake dashboards/UI chrome used decoratively
- fabricated counters such as “500+ clients” or “99% satisfaction”
- generic AI copy such as “Building Tomorrow, Today”
- all sections using the same fade-up reveal
- parallax or scroll-jacking that interferes with reading
- exaggerated 3D effects without a clear communication purpose

## Homepage Direction
### Header
Clean architectural navigation. Avoid floating pill navigation. Primary action should be visible but understated.

### Hero
Typography-first editorial composition with one large authentic project image. Include company identity, concise positioning, restrained metadata, and direct actions. No capability chips, floating cards, blur blobs, or decorative UI chrome.

### Capabilities
Use an indexed service list or asymmetric editorial matrix. Do not default to six equal icon cards.

### Selected Work
Make project photography visually dominant. Use large imagery, structured metadata, project numbering, and asymmetric layouts. Do not use a generic three-column card gallery on the homepage.

### Company / Credibility
Use real operational facts, legal readiness, process, experience, and documented evidence. Present them as structured editorial information rather than badge collections.

### Brand Ecosystem
Industry brand logos may remain, but should be visually quiet and subordinate to project work.

### Contact
End with a strong, simple conversion section. Avoid dashboard-like contact-card collections.

## Motion Language
Use motion selectively:
- text reveal using opacity + small translation
- image scale/crop movement around 1.02–1.05 maximum
- subtle project-title movement on hover
- restrained navigation transitions

Avoid bounce, elastic motion, constant floating, excessive scroll triggers, and simultaneous fade-up animations on every element. Honor `prefers-reduced-motion`.

## Visual QA
Before declaring a page complete, review screenshots at minimum at 1440px, 1024px, and 390px widths. Evaluate typography hierarchy, image crop, whitespace rhythm, alignment, section pacing, repeated patterns, authenticity of imagery/copy, motion restraint, and CTA prominence.

If the page could plausibly be mistaken for a generic AI-generated SaaS template, the design is not finished.
