# CBL Website — Human-Led Art Direction

## Objective
Create a premium corporate portfolio for CV Cakrawala Buana Lestari that feels authored by an experienced design studio, not generated from a generic AI website prompt.

## Creative Direction
**Editorial + Industrial + Architectural + Premium Corporate**

The website should communicate engineering credibility through composition, typography, authentic project documentation, measured motion, and disciplined spacing. The visual system must feel specific to CBL and its real project work.

## Core Principles
1. **Photography is evidence, not decoration.** Prefer authentic CBL project documentation over generic stock imagery.
2. **Typography carries hierarchy.** Use strong type scale, restraint, alignment, whitespace, and contrast instead of decorative UI containers.
3. **Sections should have distinct compositions.** Avoid repeating the same centered heading + card grid pattern throughout the page.
4. **Motion must explain hierarchy or add spatial continuity.** Do not animate elements merely because animation is available.
5. **Corporate credibility beats visual gimmicks.** No fabricated metrics, testimonials, awards, clients, or project claims.
6. **Use brand orange sparingly.** Orange is an accent and action color, not a background treatment for every section.
7. **Responsive design is composition-aware.** Mobile is not just desktop stacked vertically; preserve hierarchy, crop, rhythm, and reading order deliberately.

## Anti-AI-Slop Rules
The following patterns are prohibited unless there is a documented design reason:

- generic purple/blue gradients
- decorative blur blobs
- glassmorphism panels
- oversized rounded cards everywhere
- pill badges used as default section labels
- chip clouds for ordinary service lists
- floating stat/info cards over hero imagery
- icon in every heading or card
- three-column feature-card grids as the default layout
- identical card treatment across unrelated content
- fake dashboards or UI chrome used decoratively
- generic SaaS hero composition
- glowing buttons
- excessive shadows
- meaningless marquee text
- generic stock construction imagery when authentic CBL imagery exists
- all sections using the same fade-up reveal
- parallax or scroll-jacking that interferes with reading
- exaggerated 3D effects without functional purpose
- fabricated counters such as "500+ clients" or "99% satisfaction"
- generic AI copy such as "Building Tomorrow, Today" or "Transforming Ideas Into Reality"

## Homepage Composition Direction

### 1. Header
- Clean, architectural navigation.
- Logo and navigation should feel integrated into the page rather than floating inside a pill/container.
- Keep primary action visible but understated.

### 2. Hero
Replace the current SaaS-like composition with a typographic editorial hero.

Target structure:
- company identity / discipline label
- large, confident headline
- short supporting sentence
- restrained project / location metadata
- one authentic project image used at large scale
- no capability chips
- no floating information card
- no decorative blur blobs

The image should behave like an editorial photograph: deliberate crop, generous scale, minimal overlay.

### 3. Capabilities
Do not use six equal feature cards.
Use an asymmetric list, index, or editorial service matrix with meaningful hierarchy.

### 4. Selected Work
Portfolio must become visually dominant.
Prefer:
- large project imagery
- alternating / asymmetric compositions
- project number, discipline, scope, and year as structured metadata
- fewer projects visible at once, with stronger storytelling

Avoid a generic 3-column card gallery on the homepage.

### 5. Company / Credibility
Use real operational facts, legal readiness, process, experience, and documented project evidence. Present them with editorial typography and structured information rather than badge collections.

### 6. Brand / Technical Ecosystem
Partner/equipment brand logos may remain, but the presentation must be visually quiet and subordinate to project work.

### 7. Contact
End with a strong, simple conversion section. Avoid a dashboard-like collection of contact cards.

## Motion Language
Use motion selectively:
- text reveal using opacity + small masked translation
- image crop/scale transitions around 1.02–1.05 maximum
- subtle project-title movement on hover
- restrained navigation transitions
- pinned/sticky storytelling only where it materially improves project presentation

Recommended interaction durations:
- micro interaction: 140–220ms
- navigation / component transition: 220–360ms
- editorial reveal: 450–800ms

Avoid:
- bounce
- elastic motion
- constant floating
- simultaneous fade-up animations on every component
- excessive scroll-triggered effects

Honor `prefers-reduced-motion`.

## Visual Review Standard
Before considering a page complete, review screenshots at minimum at:
- 1440px desktop
- 1024px tablet/compact desktop
- 390px mobile

Evaluate:
- typography hierarchy
- image crop
- whitespace rhythm
- alignment
- section-to-section pacing
- repeated component patterns
- authenticity of imagery and copy
- motion restraint
- CTA prominence

If the page could plausibly be mistaken for a generic AI-generated SaaS template, the design is not finished.
